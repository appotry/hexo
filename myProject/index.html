Github开源项目

  • 这里部分罗列，更多开源项目见 Github 。

appotry/PTtool

方便PT用户硬链接文件，在最大可能情况下节约空间，并保持做种。 小于1M的文件直接复制，方便emby，tmm等工具刮削修改nfo等小文件。 大于1M的文件硬链接到目的目录，可以修改文件名，但是不能修改文件内容！

Docker

在个人Nas上面同时运行着80多个Docker，高峰期上百个。

包括娱乐，PT，开发，等等各种用途。精心定制整理推荐！

全部开源！请放心使用。欢迎提交PR，功能建议。

bloodstar/drop-in

VIM IDE 开发环境。All In One Docker！

bloodstar/hexo

Docker版本的Hexo，初始化自动安装常用插件和Matary主题。使你更方便的体验Hexo的魅力。

bloodstar/gitbook-builder

  • Gitbook Docker 集成开发环境。支持CJK，附带常用工具。使用它，下面一些列环境配置都可以省略了。开箱即用。

bloodstar/nginx-purge

大名鼎鼎的Nginx深度定制版本。

支持ARM64, ARMV7, AMD64 ，增加 CA 证书，防火墙，brotli, Proxy-cache-purge, htpasswd 支持 。

bloodstar/rclonebrowser

rclonebrowser 最新版本。

A docker container including RClone Browser with GUI interface.

Rclone 同步各大网盘， 实现自动备份，自动远程同步等功能。
