Wiki Writing Guide

This page summarizes how to write and maintain the yezhifashu wiki system, including multi-language conventions and gotchas.

1. Content Syntax

Wiki pages are standard Markdown (same as blog posts), rendered by hexo-renderer-markdown-it:

  • All markdown-it plugins: emoji / abbr / footnote / task lists / tables / containers / math ($...$)
  • 14 matery tag plugins: {% note %}, {% tabs %}, {% timeline %}, {% mermaid %}, {% button %}, {% label %}, {% groupimage %}, {% wechat_dialog %}, {% cardurl %} etc.
  • Container syntax (:::): ::: tip / ::: warning / ::: note / ::: info / ::: attention / ::: error / ::: hint

See Markdown Syntax and Content Tag Plugins for details.

3. Multi-language Support

3.1 Directory Structure

Each wiki sub-site lives under source/{wiki}/ (e.g. source/tutorial/); the English version goes to source/en/{wiki}/:

3.2 URL Rules

LanguageURL
Chinese (default)/tutorial/guide/writing (no prefix)
English/en/tutorial/guide/writing (/en/ prefix)

3.3 Fallback

  • With English version (source/en/ file exists) → /en/... shows English
  • Without English version → /en/... falls back to Chinese + top banner (“This page has no en version yet, showing default language content”), with noindex to prevent SEO duplication
  • Translation source convention: source/en/{wiki}/{page}.md — just add the translated file, no config change needed

3.4 Writing Tips

  1. Default language first: write Chinese first, then add English
  2. English sidebar keys: use snake_case keys in source/_data/{wiki}-sidebar.yml (e.g. getting_started); display text comes from languages/*.yml
  3. Internal links: use absolute paths + .html (e.g. /tutorial/guide/writing.html) — language prefix is added automatically
  4. After adding a page: update source/_data/{wiki}-sidebar.yml

4. Heading Numbering Gotcha (Important)

  • Theme has CSS auto-numbering (on by default): auto-numbers h2-h6 (1., 1.1, 1.1.1…)
  • Manually numbered headings (e.g. ## 1. Overview, ### 1.1 Background) will double-number with CSS auto-numbering (renders as 1. 1. Overview)
  • Manually numbered pages must set closeAutoTocNum: true (frontmatter) to disable CSS auto-numbering
  • Pages relying on CSS auto-numbering should not set that field

5. Verification

  • Local: npx hexo generate, then visit /tutorial/xxx and /en/tutorial/xxx
  • Multi-language tests: tools/tests/release-test.sh L2b section (en pages 200 + fallback banner + comment path normalization + default lang no prefix)
  • Sidebar translations: sidebar.tutorial.* entries in 9 languages/*.yml files
