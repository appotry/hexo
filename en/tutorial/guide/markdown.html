Markdown Syntax Extensions

This page summarizes the 17 markdown-it plugins enabled by the theme via hexo-renderer-markdown-it (emoji / attrs / link-attributes / abbr / footnote / ins / sub / sup / mark / task-checkbox / multimd-table / imsize / container / admon / deflist / mathjax3 / cjk-breaks; config in the root _config.yml), plus a combined example and a quick reference. Each plugin gives its purpose, syntax, example and effect — examples can be copied directly into a post for testing.

How to read this page: every syntax is shown as matched pairs of Effect → Corresponding source — see the real render first, then copy the Markdown below it. The parameter tables and “Boundaries & pitfalls” sections all come from the plugin config in _config.yml and the actual plugin source in node_modules, not guesses.

Unlike the inline bold-label style of the “Layout & Pages” chapter, this page uses third-level subheadings (minimal example / common variants / all syntax forms / parameters & options / boundaries & pitfalls / summary) because it needs to host code blocks and live rendering examples.
Note: code blocks that demonstrate syntax are always wrapped with raw tags (raw paired with endraw) to prevent nunjucks from mishandling them or swallowing following content during pre-rendering.
Note: this page contains real math formula examples (item 16), so front-matter declares mathjax: true — whenever a post body contains $...$ / $$...$$ formulas you MUST declare it, otherwise formulas display literally.

2.5 Boundaries & pitfalls

CaseBehavior
Wanting to add attributes to a tablethe attribute block must be two blank lines below the table; attached directly it does not apply

Written after an unsupported element (e.g. alone on a blank line)shown as plain text

2.6 Summary

  • {...} must sit at the end of the element’s line (tables are the exception: two blank lines below)
  • #id / .class / key=val; quote values that contain spaces
  • All attributes are allowed by default — multi-author sites should tighten the whitelist

3.5 Boundaries & pitfalls

CaseBehavior

Internal links getting rel="noopener noreferrer"no functional harm, but semantically redundant

Linked images<img> is not <a>, unaffected

3.6 Summary

  • The effect is “every <a> on the entire site opens a new tab”, not “external links only”
  • pattern is a decorative config; changing it does nothing (4.0.1 has no such branch)
  • A single link cannot be switched back to the same tab via config

  • Types are not validated, but a type without CSS only gets the base style

Common pitfalls:

  • Code blocks that demonstrate syntax MUST be wrapped with raw tags (raw/endraw paired), preventing nunjucks pre-render errors or swallowed content
  • When a post body contains $...$ / $$...$$ formulas, front-matter MUST declare mathjax: true, otherwise formulas display literally
  • Leave a blank line above and below block formulas $$...$$; escape literal $ with \$
  • link-attributes’ pattern has no effect in 4.0.1 — every body link (including internal and anchor links) gets target="_blank"; config cannot limit it to external links
  • Task list - [x] needs a space after the brackets; - [x]xxx won’t render as a task; checkboxes are a disabled display state
  • The abbr definition line *[abbr]: full name may appear anywhere (substitution happens after whole-block parsing), but must occupy its own line
  • container registers warning/note/info/attention/error/tip/hint (7 types); ::: tip / ::: hint render as info-blue callouts
  • admon starts with !!!, indents content, and closes with two consecutive blank lines; a single blank line does not end it
  • multimd-table’s ^^ is a row merge, not superscript; || spans columns
  • When combining tables with attrs, the attribute block must go two blank lines below the table
