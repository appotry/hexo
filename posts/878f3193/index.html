19.5 边界与坑

情况行为
内容不缩进只有标题进入块内，正文落在块外
折叠块 ??? note不支持：当前插件版本（1.0.1）无折叠语法，实测原样输出 ??? note
类型拼错 !!! cautoin类型照收（不校验），但主题没有对应配色，显示为无样式块
与 §11 ::: 容器混用两套独立语法：admon 产出 .admonition.<type>，container 产出 .<type>，样式不同
缩进 2 空格不足 4 空格，视为普通段落
标题加引号引号会被渲染出来（“标题”），纯属多余

19.6 小结

  • 三要素：!!! 类型、缩进 4 空格、可选标题（不加引号）
  • 想折叠 → 用 {% note %}，admon 的 ??? 在这个版本不存在
  • 类型不校验，拼错不报错但没样式

测试断言：页面含 admon 渲染标记。

⚠️ 已知坑

坑 1：标题编号双重叠加

现象：标题渲染为「1. 1. 概述」（两个编号）。

原因：主题 CSS 自动给 h2–h6 加编号（默认开启），手写编号（如 ## 1. 概述）会叠加。

正确做法：手写编号的页面在 front-matter 加 closeAutoTocNum: true；不手写编号的页面不要加该字段。

本文已正确设置 closeAutoTocNum: true。

坑 2：{% raw %}` 忘了包 **现象**：示例源码里的 `{% note %}`、`{{ }}` 被真实执行或报模板错误。 **正确做法**：所有含 `{% %}` / `{{ }}` 的示例代码块都用 `{% raw %}` … `{% endraw %} 包住。

坑 3：配置项写了不生效

现象：link-attributes 的 pattern: ^https?://、mathjax3 的 inlineMath 都写了，但行为没变。

原因：两处都是插件不认这个键（一个只认 matcher 函数，一个是源码硬编码 $/$$），配置静默失效。

坑 4：改配置后必须 clean 构建

现象：修改根 _config.yml 的 markdown.plugins（如切换 mathjax/katex 引擎、开 multiline）后页面不变。

原因：Hexo 缓存机制不会自动检测配置变更。

正确做法：改 markdown 插件配置后必须 npm run clean && npm run build。
