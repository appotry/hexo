内容 Tag 插件

本页汇总 matery 主题的 14 个内容 tag 插件：note 便签、timeline 时间线、tabs 标签页、label 行内标签、button 按钮、githubCard GitHub 卡片、mermaid 图表、pdf 嵌入、insertmd 片段插入、wechat_dialog 微信对话、groupimage 分组图片、cardurl URL 卡片、admonition 容器、encrypt 片段加密。每个插件给出用途、语法、示例、效果，示例可直接复制到文章测试。

怎么读这页：每个插件都按「效果 → 对应源码」成对展示——先看页面真实渲染，再抄下面的 Markdown 源码。参数表里的默认值全部取自 themes/matery/scripts/tags/*.js 的实际代码，不是猜的。

与「布局与页面」的行内加粗标签风格不同，本页因需容纳代码块与真实渲染示例，采用三级子标题（最小示例/常用变体/完整参数/进阶组合/边界与坑/小结）分隔。前 12 个为主题原生注册的 tag（themes/matery/scripts/tags/index.js 统一注册），admonition 由 markdown-it-container 插件提供（根 _config.yml 注册 7 种容器：warning/note/info/attention/error/tip/hint）。
注意：在 Markdown 代码块中展示 {% xxx %} 这类 tag 语法时，必须用 raw 标签包裹（raw 与 endraw 成对），否则 nunjucks 会预渲染导致构建报 unknown block tag。

1.8 小结

  • 最常用：note info / note warning 两三个词就够
  • 想折叠：颜色后直接写标题
  • 想纯色块无图标：加 no-icon
  • 想嵌套：正文里继续写 tag（记得成对闭合）

颜色写错类名照样输出，只是没有对应 CSS，退化为默认色
只想要纯列表不用 timeline，直接写 Markdown 列表更轻量

2.7 小结

  • 记住两件事：节点标记必须独占一行，endtimeline 必须闭合
  • 标题可省：不想要总标题就不写参数
  • 颜色是 CSS 类名，写错不报错但没效果

6.3 完整参数

github-card.js 把每个参数按第一个冒号切成 key/value，再拼成 data-* 属性交给前端 JS。

参数必填默认说明

6.4 进阶/组合

  • 无 JS 时显示 <noscript> 提示；API 失败时前端降级为普通链接。
  • 同一页放太多卡片会撞 GitHub 未认证 API 限额（60 次/小时/IP），演示页建议 ≤2 个。

6.5 边界与坑

情况行为
缺 user构建日志 error，渲染红字配置错误提示
参数值含空格Hexo 按空格切参数 → 值被截断
写 theme:default / target:blank不输出对应属性（等于没写），不是错误
写 client_secret:xxx被忽略（代码里没有这个键），不会泄露也不会生效
用逗号分隔参数不支持，key:value 之间只能用空格

6.6 小结

  • 最小可用：user:xxx repo:yyy
  • 尺寸写数字即可，px 会自动去掉
  • 需要高限额用 client_id，永远别放 secret

  • 三参数：密码（必填）→ 标题 → 简介
  • 密码绝不能省，否则内容明文泄露
  • 片段内部可以正常用其它 tag

附：tag 插件速查表

插件语法关键参数是否需 front-matter
note{% note 颜色 %}内容{% endnote %}6 色 + no-icon + 标题折叠否
timeline{% timeline 标题,颜色 %}...{% endtimeline %}标题 / 颜色否
tabs{% tabs 名称,序号 %}...{% endtabs %}名称（必填） / 激活序号否
label{% label 颜色@文字 %}颜色在前文字在后否
button{% button 链接,文字,图标,title %}链接第一 / 文字第二否
githubCard{% githubCard user:xx repo:yy %}user 必填 / repo / width / height / theme / target / client_id否
mermaid{% mermaid %}...{% endmermaid %}图表类型（graph / sequenceDiagram / classDiagram）是（mermaid: true）
pdf{% pdf URL %}URL（自动识别 googledoc / slideshare / normal）否
insertmd{% insertmd '路径.md' %}相对 source/ 的路径或目录 + 分隔符否
wechat_dialog{% wechat_dialog %}User:/Assistant: 行{% endwechat_dialog %}User/Assistant 行格式否
groupimage{% groupimage 数量 布局 %}![图](url){% endgroupimage %}数量 2–10 / 布局 - 分隔否
cardurl{% cardurl [url=xx] [title=xx] [desc=xx] [avatar=xx] %}url 必填 / desc 建议必填否
admonition::: 类型 内容 :::warning / note / info / attention / error / tip / hint否（根 _config.yml 全局启用）
encrypt{% encrypt 密码 "标题" "简介" %}...{% endencrypt %}密码必填 / 标题 / 简介否
markmap{% markmap 650px %}列表{% endmarkmap %}高度参数 / 内容为 Markdown 列表否

常见坑：

  • 代码块内展示 {% xxx %} 语法必须用 raw 标签包裹，否则构建报 unknown block tag
  • label 颜色在 @ 前、文字在 @ 后；button 链接在第一个参数
  • mermaid 忘记 front-matter mermaid: true 时图表不渲染（specific 模式）
  • wechat_dialog 只认 User: / Assistant: 行首格式（大小写敏感），不是行内参数
  • timeline / tabs 的 <!-- xxx --> 标记后必须换行，否则该节点被静默丢弃
  • cardurl 省略 desc 会显示 undefined，务必写上
  • groupimage 的布局各数之和必须等于图片数量，否则静默回退默认布局
  • encrypt 忘记密码会明文输出内容，不会报错
  • 构建失败时先看构建日志有无 Nunjucks Error，再检查对应 tag 语法
