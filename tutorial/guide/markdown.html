Markdown 语法扩展

本页汇总主题通过 hexo-renderer-markdown-it 启用的 17 个 markdown-it 插件（emoji / attrs / link-attributes / abbr / footnote / ins / sub / sup / mark / task-checkbox / multimd-table / imsize / container / admon / deflist / mathjax3 / cjk-breaks，配置见根 _config.yml），外加综合示例与速查表。每个插件给出用途、语法、示例、效果，示例可直接复制到文章测试。

怎么读这页：每个语法都按「效果 → 对应源码」成对展示——先看页面真实渲染，再抄下面的 Markdown 源码。参数表与「边界与坑」全部取自 _config.yml 的插件配置和 node_modules 里插件的实际源码，不是猜的。

与「布局与页面」的行内加粗标签风格不同，本页因需容纳代码块与真实渲染示例，采用三级子标题（最小示例/常用变体/全部写法/参数与选项/边界与坑/小结）分隔。
注意：展示语法的代码块一律用 raw 标签包裹（raw 与 endraw 成对），防止 nunjucks 预渲染时误处理或吞掉后续内容。
注意：本文含真实数学公式示例（第 16 项），因此 front-matter 已声明 mathjax: true——文章正文出现 $...$ / $$...$$ 公式时都必须声明它，否则公式原样显示。

2.5 边界与坑

情况行为

值里有空格却没用双引号只取第一段，剩余部分当正文
写在不支持的元素后（如空行单独一行）原样显示为文本

2.6 小结

  • {...} 必须贴在元素行尾（表格是例外：下方空两行）
  • #id / .class / key=val，值含空格加双引号
  • 默认放行所有属性，多作者站点要收紧白名单

图片外链<img> 不是 <a>，不受影响

3.6 小结

  • pattern 是装饰性配置，改它没用（4.0.1 无此分支）
  • 单链接想改回本窗口，靠配置做不到
