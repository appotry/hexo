交互与视觉

本页梳理 matery 主题的交互与视觉功能：代码块增强、图片灯箱、打字机、页面特效、繁简转换、阅读进度、返回顶部、打赏、打印样式、音视频播放器与图表。每个功能给出配置位置与使用方法。

怎么读这页：每个功能都按「效果 → 对应配置」成对展示——先看它产出什么，再抄下面那段 YAML。参数表里的键全部出现在本页或 userConfig/_config.tmp.yml 中，未验证的值一律标注「其他值未验证」。

配置位置均在主题配置 themes/matery/_config.yml（文内简写"主题配置"）。注意：本项目 CI 构建时主题配置文件会被 userConfig/_config.tmp.yml 模板覆盖，修改请同步模板（见「安装与主题配置」篇）。部分功能无独立配置键（返回顶部、打印样式），由主题内置、开箱即用。

  • 点了没反应：先看 lightgallery 资源是否加载成功。

  • 小节标题也在动：那是 post.typed，独立开关。

效果：读取 window.Matery.effects（由模板注入的配置元数据）并按 page / mouse 各自的值加载脚本；无配置时是空操作、不报错。

对应调用：

4.3 全部可调项

键类型默认可选值/范围作用
effects.enablebooltruetrue / false总开关：面板"页面特效"区是否显示
effects.desktop_onlybooltruetrue / false是否只在桌面端注入
effects.page.defaultstringoffoff / random / available 中任一 id页面特效默认项（单选）
effects.page.available.<id>.labelstring—任意显示名面板显示文案
effects.page.available.<id>.libstring—sakura ripples leaf snowdown snowflake buble canvas_nest ribbon ribbon_dynamic实际加载的库
effects.mouse.defaultstringoffoff / random / available 中任一 id鼠标特效默认项（单选）
effects.mouse.available.<id>.labelstring—任意显示名面板显示文案
effects.mouse.available.<id>.libstring—clicklove popupText star fireworks实际加载的库
localStorage["matery.effect.page"]string—off / random / id运行时页面特效偏好
localStorage["matery.effect.mouse"]string—off / random / id运行时鼠标特效偏好

lib 对应 theme.libs.js.* 路径键；canvas_nest / ribbon 还支持 params 子键（颜色、数量等），其余库的 params 未验证。

4.4 边界与冲突

  • page 与 mouse 两组各自单选：同组内配多个只有 default 指定的那个生效。
  • 两组各自独立持久化：matery.effect.page 与 matery.effect.mouse 互不干扰；面板切换后刷新页面才生效。
  • 桌面端门槛：desktop_only: true 时，仅当窗口宽度 > 断点 BP.fun（约 992px）且本地访问计数 > 1 才注入；移动端与首次访客不加载。
  • 旧版独立的 sakura / ripples / clicklove 等 enable 配置段已删除，不再参与注入；增删特效改 available 清单即可，面板与运行时自动适配。
  • 运行时逻辑在 themes/matery/source/js/plugins.js（Matery.plugins.effects）；配置元数据由 themes/matery/layout/_partial/script/effects.ejs 注入 window.Matery.effects。

4.5 小结

  • 最小可用：effects.enable + page.default 一行选特效。
  • 同组配多个没用：只有 default 生效。
  • 桌面看不到：先看宽度是否超过断点，再看访问计数（首访不注入）。
  • 想改主意：用悬浮面板切，别反复改配置。

background.image.lightNumnumber45非负整数亮色随机图数量
background.image.lightPathstring/medias_webp/featureimages/目录路径亮色图库路径
background.image.darkNumnumber22非负整数暗色随机图数量
background.image.darkPathstring/medias_webp/featureimages/dark/目录路径暗色图库路径
background.video.enablebooltruetrue / false视频背景开关
background.video.urlstring/video_url.json?v=1.0.0JSON 路径视频列表地址
background.loading.enablebooltruetrue / false加载动画开关
background.loading.typestring"off"off / 1 / 2 / 3默认动画类型
background.loading.timenumber350ms强制开启时长
localStorage["matery.bg"]string—off / image / video运行时背景偏好
localStorage["matery.loading"]string—off / 1 / 2 / 3运行时加载动画偏好

16.4 边界与冲突

  • 开关层级为 background.enable（总）→ 各子 enable → 面板选择；任一层关闭即不渲染。
  • random: true 时按明暗主题从 lightPath / darkPath 图库随机取图，lightNum / darkNum 是可用图片数（从 0 开始编号）。
  • 视频背景的 brightness 字段由亮暗主题过滤（封面灰度 ≥90 为 bright / <90 为 dark）。
  • 图片与视频互斥（面板单选 matery.bg），加载动画独立单选。
  • 与 §4 effects 是两套机制：背景管底层画面，特效管飘落/点击动画。

16.5 小结

  • 最小可用：background.enable + default: image。
  • 每次换图：random: true + 图库路径与数量。
  • 想关掉背景区：background.enable: false（面板里对应区域也消失）。

17. 偏好面板（right-floating）

用途：右下角悬浮按钮组中的齿轮按钮（#fp-toggle）唤出"偏好设置"面板，读者无需改代码即可调整阅读偏好。面板本体恒显示，其中"特效""背景"区分别由 effects.enable / background.enable 控制显隐。

学习路径：字体缩放 → 语言/简繁 → 显示模式 → 特效与背景 → 分区一览

17.1 如何启用

效果：右下角出现齿轮按钮，点击展开面板，内含字体缩放、语言/简繁、显示模式、页面特效、鼠标特效、网页背景、加载动画七个分区；所有选择跨页面持久保留。

对应配置：面板本体恒显示，无 YAML 总开关；其中"特效"区由 effects.enable 控制、"背景"区由 background.enable 控制。

17.4 边界与冲突

  • 面板本体恒显示；只有"特效""背景"两区受 effects.enable / background.enable 控制显隐。
  • 字体缩放改的是 <html> 上的 --font-scale，根字号 = calc(--font-size-base × --font-scale)（默认 16px × 1）；直接写死 px 的样式不跟随缩放。
  • 显示模式与 color-schema.js 共用同一个 localStorage 键，两处入口（菜单按钮 / 面板）互相同步。
  • 涉及文件：模板 themes/matery/layout/_partial/common/right-floating.ejs；字号变量 themes/matery/source/css/_pages/_base/base.styl、color-schema.styl。

17.5 小结

  • 读者自助：绝大多数偏好问题先让读者用面板调，不用改配置。
  • 两区可藏：effects.enable / background.enable 关掉即从面板消失。
  • 直连存储：所有偏好都在 localStorage，清掉即回落配置默认值。
