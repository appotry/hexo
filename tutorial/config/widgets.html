侧边栏组件

本页讲解侧边栏与首页小部件：页面级统计组件（标签云/词云/分类雷达/归档/图表）、Live2D 看板娘、音乐播放器。前两者由主题自动渲染，后两者有独立配置。

主题配置以 userConfig/_config.tmp.yml 为权威源（CI 时覆盖主题配置）。

阅读方式：每节都按「如何启用 → 常用选项 → 全部可调项 → 边界与冲突」展开，先看效果，再看产生该效果的对应配置，复制即可用。

1. 页面级组件（自动渲染）

用途：以下组件由主题生成器按页面自动渲染，无需配置，随内容自动更新。

学习路径：如何启用 → 常用选项 → 全部可调项 → 边界与冲突

1.1 如何启用

效果：打开 /tags/ 看到标签 chip 列表 + canvas 词云（字号 ∝ 文章数）；打开 /categories/ 看到分类云 + 雷达图；打开 /archives/ 看到时间线与日历。不需要改任何配置，建好内容即出现。

对应配置：无（组件由 layout 模板自动挂载）。

1.2 常用选项

① 调整标签云内容

效果：标签列表与词云的词、字号分布随文章 tags 变化；新增标签后词云多一项。

对应配置（文章 front-matter）：

② 调整分类雷达图

效果：雷达图的轴与数值随 categories 变化；分类层级越深，分布越细。

对应配置（文章 front-matter）：

1.3 全部可调项

组件清单（对应 themes/matery/layout/_partial/widget/ 目录）：

页面组件说明
/tags/标签云 tag-cloud + 词云 tag-wordcloudchip 样式标签列表；canvas 词云字号 ∝ 文章数
/categories/分类云 category-cloud + 雷达图 category-radarcanvas 雷达图展示各分类文章数量分布
/archives/时间线 + 日历 post-calendar按年/月时间线，圆点 + 年份折叠
/about/站点统计图表 post-charts多组 canvas 图表（文章数/分类/标签/时间线等）
文章页分类栏 category-bar当前分类下文章（配置见「文章页配置」篇）

1.4 边界与冲突

  • 这些组件挂在对应 layout 上，页面数据来自站点内容本身。
  • 想"配置"它们，本质是调整内容结构（如标签命名、分类层级），或修改 themes/matery/layout/_partial/widget/*.ejs 模板（高级定制）。
  • 没有文章时词云/雷达图会显示空图，不是配置错误。

1.5 小结

  • 最小可用：什么都不用配，发文章即可
  • 想改分布：调标签/分类命名与层级
  • 想改样式：改 _partial/widget/*.ejs
  • 空图：先确认有已发布文章

2.3 全部可调项

键类型默认可选值/范围作用
live2dWidget.enablebooltruetrue / false看板娘总开关
libs.js.live2dAutoloadstring/libs/live2d/autoload.js脚本路径自动加载入口
source/live2d/model_list.jsonfile—模型清单可切换的模型

waifu-tips.jsonfile—提示语 JSON气泡文案
菜单项 class: menu-2d-*string—menu-2d-*提示框定位选择器

2.4 边界与冲突

  • 模型与提示语配置在 source/live2d/（模型静态化）与 waifu-tips 相关文件中，独立于主题配置管理。
  • 菜单项里的 class: menu-2d-*（如 menu-2d-home）是看板娘提示文字框的定位选择器（见「导航菜单与首页」篇）。
  • 模型添加/删除/切换的完整操作见博客的 live2d 维护文档。
  • 双运行时：Cubism 2（live2d.min.js）与 Cubism 5（live2dcubismcore.min.js）并存，autoload.js 按模型版本分别加载（cubism2Path / cubism5Path）。
  • 本地模型：模型与清单位于 source/live2d/model/ 与 source/live2d/model_list.json。
  • 真实配置键：主题配置仅 live2dWidget.enable 一个开关；自动加载脚本路径为 libs.js.live2dAutoload → /libs/live2d/autoload.js，运行时资源（autoload.js / waifu-tips.js / waifu.css）在 themes/matery/source/libs/live2d/。
  • 提示语可配置：是——autoload.js 以 waifuPath 指向 waifu-tips.json，改该文件即可自定义提示语。
  • 暗色适配：waifu.css 同时支持手动暗色（[data-user-color-scheme="dark"]）与系统偏好（prefers-color-scheme: dark）。
  • 加载门槛：layout/_partial/script/live2d.ejs 仅在窗口宽度 > BP.fun 且访问计数 > 2 时加载。

2.5 小结

  • 最小可用：live2dWidget.enable: true
  • 换角色：改 model_list.json + model/
  • 改台词：改 waifu-tips.json
  • 不显示：先看窗口宽度与访问计数门槛

  • title 仅在非吸底模式有效（吸底条没有标题栏）。

3.5 小结

  • 最小可用：enable + server + type + id
  • 全站背景音乐：musics.fixed: true
  • 不想自动响：autoplay: false
  • 音量不生效：用户手动调过，属预期行为
